JSON → Slides Generator

Paste JSON, download a .pptx, open in Google Slides

JSON Input

▸ JSON format reference 
[
  {
    "title": "Slide title here",
    "text":  "Body text for the slide.",
    "image": "https://example.com/photo.jpg"
  },
  {
    "title": "Text-only slide",
    "text":  "No image field needed."
  }
]

Fields:
  title  — required, slide heading
  text   — optional, body text
  image  — optional, any public image URL
